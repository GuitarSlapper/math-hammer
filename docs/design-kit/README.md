# MathHammer — исходный дизайн-комплект

Ресурсы, предоставленные для разработки приложения. Макеты служат визуальным ориентиром;
интерфейс реализуется нативными Compose-компонентами.

- [Актуальное техническое задание](../SPECIFICATION.md).
- [Дизайн-токены и рекомендации](../DESIGN_GUIDE.md).
- [Первоначальное ТЗ v1](../archive/SPECIFICATION_V1.md).

## Ресурсы

| Каталог | Содержимое |
|---|---|
| `references_v2/01`–`05` | Актуальные калькулятор, сохранение, история, переименование и пустое состояние |
| `references_v2/00_screens_overview.png` | Согласованный обзор экранов |
| `references_v2/00_v2_concept_board.png` | Художественный концепт; не определяет функциональность |
| `references/` | Исторические референсы первого дизайна |
| `ui-elements-v2/` | Отдельные визуальные компоненты истории |
| `ui-icons/` | Исходные SVG и PNG пиктограмм |
| `icon/` | Варианты основной иконки и адаптивного foreground |
| `android/res/` | Исходные заготовки Android-ресурсов |

Шрифт Exo 2 встроен в приложение: `app/src/main/res/font/exo2.ttf` относительно корня репозитория.
Лицензия OFL включена в `app/src/main/assets/licenses/Exo2-OFL.txt`.
Актуальные ресурсы приложения находятся в `app/src/main/res`; этот каталог хранит исходные материалы.
